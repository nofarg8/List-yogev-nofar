חיבור המכשיר לגיטהאב

כדי לשמור שינויים צריך לחבר את המכשיר הזה פעם אחת.

הרשימה נשמרת בקובץ data.json במאגר שלכם. כדי שהמכשיר יוכל לשמור, מדביקים כאן מפתח גישה של גיטהאב. עושים את זה פעם אחת בכל טלפון או מחשב.

  1. נכנסים ליצירת מפתח בגיטהאב (מחוברים לחשבון nofarg8).
  2. ב-Token name כותבים שם, למשל: טלפון של נופר.
  3. ב-Expiration בוחרים No expiration, או שנה קדימה. אחרת המפתח יפסיק לעבוד אחרי 30 יום.
  4. ב-Repository access בוחרים Only select repositories, ובתפריט שנפתח בוחרים את List-yogev-nofar.
  5. ב-Permissions לוחצים Add permissions (או פותחים Repository permissions), בוחרים Contents, ומשנים את Access ל-Read and write.
  6. לוחצים Generate token למטה, ומאשרים שוב אם מתבקשים.
  7. מעתיקים את המפתח שמתחיל ב-github_pat_ ומדביקים אותו כאן. גיטהאב מציג אותו פעם אחת בלבד.

זה בחינם. ליוגב אפשר לשלוח את אותו מפתח בהודעה פרטית ולהדביק גם אצלו.

המפתח נשמר רק בדפדפן של המכשיר הזה.
