# דברים לעשות – יוגב ונופר

רשימת משימות משותפת לפי ימים, בעיצוב בורדר קולי.

- `index.html` – האתר כולו.
- `data.json` – הימים והמשימות. כל סימון, הוספה או עריכה באתר נשמרים כאן כעדכון במאגר.
- `assets/hero.jpg` – תמונת הבאנר. `assets/og-image.jpg` – התמונה שמופיעה כששולחים את הקישור בוואטסאפ.

## הפעלה כאתר
Settings ← Pages ← Source: Deploy from a branch ← Branch: `main`, תיקייה `/ (root)` ← Save.
אחרי דקה-שתיים האתר זמין בכתובת `https://nofarg8.github.io/List-yogev-nofar/`.

## חיבור מכשיר לשמירה
באתר לוחצים "חיבור לגיטהאב" ומדביקים מפתח גישה (Fine-grained token) עם גישה רק למאגר הזה והרשאת Contents: Read and write.
מחברים פעם אחת בכל טלפון או מחשב. בלי מפתח האתר מוצג לקריאה בלבד.
